Python Home Assistant custom integration. Runtime target is Python 3.12+ and HA >= 2025.1. Runtime manifest has no external requirements; voluptuous/HA helpers are bundled. Tests use pytest, pytest-asyncio, pytest-cov, pytest-homeassistant-custom-component. Dockerfile.test pins HA 2025.1.4 by default and includes ruff/mypy. Repository also contains external/ReqogniLoom as a submodule: do not edit it from the parent repo.
