Windows project commands: run tests with `pytest tests/ -v --cov=custom_components/abstractor --cov-report=term-missing` (normally in Docker because HA test plugin imports Unix-only fcntl on native Windows); Docker test stack: `docker compose -f docker-compose.test.yml build`, then `docker compose -f docker-compose.test.yml run --rm test`; lint/type checks via `docker compose -f docker-compose.test.yml --profile lint run --rm lint`. Use `rtk` prefixes for shell commands when available, except raw commands for debugging failures.
