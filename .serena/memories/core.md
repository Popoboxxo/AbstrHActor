AbstrHActor is a Home Assistant custom integration under custom_components/abstractor. Current implemented scope is an MVP pipeline: config/options flow -> shared DataUpdateCoordinator -> per-entry AbstractorFilterPipeline -> AbstractorSensor. Supported types: power, energy, water. Snapshot/diagnostics/services exist. The AGENTS architecture describes future bridge, sensor-type, binary_sensor, switch, and repository layers, but most are not implemented. Read `mem:tech_stack` for runtime/dependency details, `mem:conventions` for HA-specific invariants, and `mem:task_completion` for validation commands.
